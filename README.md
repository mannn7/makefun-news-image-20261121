One image summing up the world's news of **Saturday, 21 November 2026** —
six stories from six fields, drawn as a newspaper-style infographic:

1. **Ukraine** — Russian ballistic strike on Kryvyi Rih kills 2, wounds 60.
2. **Climate** — COP31 talks in Antalya run into overtime with no deal on fossil fuels.
3. **Mexico** — FBI most-wanted cartel boss "El Chapo Isidro" captured in Sinaloa.
4. **Markets** — AI stock sell-off: S&P 500 falls 3.7% into correction, Nikkei down 5.1%.
5. **Space** — ESA–JAXA probe BepiColombo enters orbit around Mercury after 8 years.
6. **Peru** — Magnitude 6.7 earthquake shakes the Andes, felt in Lima; no deaths reported.

The image (`entry.png`, 1024×1024) was drawn with Python/PIL — every shape
and label is deterministic vector-style drawing, no AI image generation.
`main.ts` (Node 22, stdlib only) copies it to `$MAKEFUN_OUTPUT_DIR/entry.png`.

## Run

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

## Sources

AP, Reuters, Wall Street Journal, Nature, AFP — each story confirmed by at
least two independent news outlets on 21 November 2026.
